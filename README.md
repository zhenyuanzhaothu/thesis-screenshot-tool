# 论文截图工具（macOS）

这是一个可配置页数和书名的图形化版本。运行时依次记录「下一页箭头」「正文左上角」「正文右下角」，随后自动截图并在桌面 `论文截图工具输出` 文件夹生成 PDF。

## 给最终使用者

请使用构建完成后的 `论文截图工具.app`。双击即可使用，不需要安装 Python 或配置环境。

首次使用时，macOS 会要求权限。请到「系统设置 → 隐私与安全性」中为该 App 开启：

- 屏幕录制
- 辅助功能

如果 macOS 阻止打开来自未知开发者的 App，请在 Finder 中按住 Control 单击该 App，选择「打开」。

## 在 Mac 上构建 App（只需执行一次）

1. 将整个文件夹复制到一台 Mac。
2. 在终端运行：

   ```zsh
   chmod +x build_macos.command
   ./build_macos.command
   ```

3. 完成后取得 `dist/论文截图工具.app`，把它交给使用者。

构建 Mac 需要联网下载构建依赖及 Xcode Command Line Tools（macOS 如果提示安装，请确认安装）；这是构建步骤的要求，最终使用者不需要这些环境。

## 使用注意事项

- 开始前，请让浏览器 PDF 阅读器显示在当前页面；倒计时结束后不要操作鼠标键盘。
- 默认翻页等待为 0.8 秒。若网页加载较慢，可在 `app.py` 中将 `time.sleep(0.8)` 调大，例如 `1.5`。
- 运行中会占用鼠标，必要时把鼠标移到屏幕左上角可触发 PyAutoGUI 的紧急中止机制。
